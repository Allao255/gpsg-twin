# Glossário

| Palavra | Significado |
|---|---|
| Almanaque | Tabela com as posições aproximadas dos satélites. O simulador usa para saber quais satélites "estão no céu" |
| Altitude Rate | Quanto o veículo sobe ou desce por minuto. Negativo: descendo |
| Análise | A aba do site que mostra mapa, linha do tempo e resumo |
| Cenário | Tudo o que você montou para um ensaio: configuração, posição ou rota, nível do sinal. É o que o site guarda e transforma em arquivos |
| Coupler (acoplador) | Peça colocada sobre a antena do receptor para levar o sinal sem cabo direto |
| dBm | Unidade de potência do sinal. Quanto mais negativo, mais fraco. -120 dBm é um sinal fraco, típico de GPS |
| Direct | Saída de sinal por cabo direto até o receptor |
| Dynamic | Tipo de simulação em que o receptor se move por uma rota |
| Folha de sessão | Resumo de uma página que vem no pacote, para levar à bancada |
| GNSS | Nome geral dos sistemas de navegação por satélite: GPS, Galileo e outros |
| GPSG-1000 | O simulador de sinais de GPS e Galileo da VIAVI |
| Loop | Repetir a rota: ao chegar no último ponto, volta ao primeiro |
| Motion Model | Tipo de veículo simulado. Limita velocidade e aceleração |
| Pacote | O arquivo `.zip` gerado pelo site, com tudo o que vai para o pendrive |
| Pendrive FAT32 | Pendrive no formato mais comum, que o equipamento consegue ler |
| PRN | Número que identifica cada satélite |
| Receptor | O aparelho de GPS que está sendo testado |
| RF Level | Nível do sinal que sai do simulador |
| Rota | Lista de pontos que o receptor "percorre" durante a simulação |
| Run e Stop | Começar e parar a simulação |
| Script | A configuração escrita em texto, uma instrução por linha. O site gera sozinho a partir da tela |
| Static | Tipo de simulação em que o receptor fica parado num lugar |
| Trajectory | Tipo de simulação que segue um caminho gravado num arquivo, em vez de pontos |
| Turn Radius | Raio da curva num ponto da rota. Quanto maior, mais suave a curva |
| UTC | Hora universal, usada pelo GPS. No Brasil, em geral 3 horas à frente do horário de Brasília |
| Waypoint | Ponto com nome, guardado para usar em rotas |
| `twin_` | Começo do nome de todo arquivo que o site cria no equipamento. Serve para não confundir com arquivos de outras pessoas |
