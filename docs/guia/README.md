| [01-verificar-script.md](01-verificar-script.md) | Conferir um script `.scpi` antes da bancada | M1 |
| [02-referencia-de-comandos.md](02-referencia-de-comandos.md) | Consultar um comando, faixa ou discrepância | M1 |
| [03-ensaiar-com-o-mock.md](03-ensaiar-com-o-mock.md) | Ensaiar script e runner contra o mock; gerar o runner colável | M2 |
| [04-montar-cenario.md](04-montar-cenario.md) | Montar um cenário na réplica, com rota, waypoints, arquivos e linha do tempo | M3 |
