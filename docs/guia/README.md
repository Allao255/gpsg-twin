# Guia de uso

O gpsg-twin ajuda a preparar ensaios no simulador de GPS GPSG-1000 sem ocupar o equipamento. Você monta tudo aqui (rota, posição, nível do sinal), confere se faz sentido e leva para o equipamento num pendrive.

Pode explorar à vontade: **nenhum botão deste site mexe no equipamento**. O site não se conecta a ele.

## O que o site faz

- Mostra uma cópia das telas do GPSG-1000. Você clica nos campos como faria no aparelho.
- Avisa quando um valor não é aceito e explica o motivo.
- Mostra a rota no mapa e uma linha do tempo do ensaio.
- Gera os arquivos para levar ao equipamento no pendrive.

## O que o site não faz

- Não liga, não desliga e não configura o equipamento sozinho.
- Não gera sinal de GPS.
- Ainda não mostra quais satélites estariam no céu.

## Dicas

- O site também funciona sem internet: basta dar dois cliques no arquivo `gpsg-twin.html`.
- O seu trabalho fica guardado no navegador deste computador. Para não perder, baixe uma cópia (veja [Primeiros passos](01-primeiros-passos.md)).
- Ficou em dúvida sobre uma palavra? Veja o [Glossário](07-glossario.md).
