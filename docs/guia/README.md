# Guia de uso

Uma página por tarefa, para quem opera o twin e o equipamento. Publicado na aba Ajuda do site e do HTML único, ao lado da referência de comandos, que é gerada do modelo e não é editada à mão. No editor de script, as sugestões (ao digitar ou com Ctrl+Espaço) e a dica ao passar o mouse sobre um comando vêm do mesmo modelo.

| Página | Tarefa |
|---|---|
| [01-verificar-script.md](01-verificar-script.md) | Conferir um script `.scpi` antes da bancada |
| [02-referencia-de-comandos.md](02-referencia-de-comandos.md) | Consultar um comando, faixa ou discrepância |
| [03-ensaiar-com-o-mock.md](03-ensaiar-com-o-mock.md) | Ensaiar script e runner contra o mock; gerar o runner colável |
| [04-montar-cenario.md](04-montar-cenario.md) | Montar um cenário na réplica, com rota, waypoints, arquivos e linha do tempo |
| [05-pacote-usb.md](05-pacote-usb.md) | Anexar almanaque e trajetória, exportar o pacote USB, abrir pacotes, arquivos do equipamento e logs |
| [06-folha-de-bancada.md](06-folha-de-bancada.md) | Folha de uma página para a bancada: conexões, ordem, regras, recuperação |
| [07-referencia-rapida.md](07-referencia-rapida.md) | Níveis, perdas, manipulações por SV, limites de movimento, conector Aux, arquivos |
| [08-conferir-na-analise.md](08-conferir-na-analise.md) | Conferir na aba Análise: linha do tempo, estado no instante, mapa, checagens de rota |
