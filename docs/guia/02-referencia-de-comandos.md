# Consultar a referência de comandos

1. Abrir a aba Ajuda.
2. Buscar por cabeçalho, forma curta (`RFLV`), nome de parâmetro ou ID de discrepância (`D17`).
3. Filtrar por categoria, tipo (ajuste, consulta, ação), "verificado em bancada" ou "com discrepância".
4. Abrir o comando para ver forma longa, parâmetros com faixa e unidade, retorno, exemplo do manual, página `RP x-y` e o tratamento provisório de cada discrepância.

Marcadores:

| Marcador | Significado |
|---|---|
| verificado em bancada | Confirmado no equipamento (`verified_on_hw`) |
| trava em execução | Rejeitado com a simulação rodando |
| nunca emitido | O twin não gera o comando (`*RST`, calibração, senha) |
| `Dnn` | Discrepância aberta; passar o mouse mostra o resumo |
